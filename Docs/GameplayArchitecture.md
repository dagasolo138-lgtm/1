# 玩法架构 v0.4

## 目标

第一阶段不做复杂关系、导演、剧情生成。只验证：建设、生产、物流、劳动力分配、生活需求、地图空间、灵气/五行布局、修炼成长是否本身好玩。

## 当前核心循环

1. 初始仓库只提供有限启动物资。
2. 地图存在古灵木、巨石、金纹矿、灵草丛、灵晶等自然资源点。
3. 玩家左键指定资源点后才生成 Gather Job。
4. 弟子采集完成后产物落地为 Output 资源堆，再进入现有物流系统。
5. 玩家放置建筑后先生成工地，材料通过 Haul Job 运到现场。
6. 材料齐全后产生 Build Job，弟子施工完成建筑。
7. 多格建筑真实占据多个格子，并成为 A* 寻路障碍。
8. 石板路不占建筑格，但提供更低寻路成本和更高移动速度；A* 会主动偏好道路。
9. 生产建筑产生本地 Input/Output 容器，资源必须实际搬入搬出。
10. 仓库过滤与物流优先级决定资源最终流向。
11. 弟子持续消耗饱食和体力，吃饭与休息会占用时间和库存/床位。
12. 灵气场与五行场同时影响空间价值；建筑所属五行受到相生/相克环境影响，从而改变工作耗时。
13. 玩家通过工作优先级 UI 调整搬运、建造、采集、种植、制造、修炼的劳动力分配。

## 地图与寻路

`GridMap` 现在承担三类数据：

- 占地：建筑、工地、自然资源节点。
- 道路：每格保存移动速度倍率。
- 寻路：四方向 A*，普通地面成本为 1，道路成本按速度倍率折算，因此角色会主动选择整体更快的道路线路。

建筑 Definition 增加 `footprint`。灵田、工坊、仓库、聚灵台为 2x2，简易床为 1x2。工地创建、取消、完工以及建筑销毁都按整个 footprint 占用/释放。

当前仍是小地图原型，因此 A* 使用简单开放列表扫描，24x24 地图足够。以后扩大地图或人口后再换二叉堆/分区寻路，不提前复杂化。

## 自然资源与采集

`NaturalResourceNode`：

- 占据一个格子并影响寻路。
- 自带资源类型、产量、采集工作量。
- 默认不生成工作，玩家通过 `GatherDesignationController` 点击指定后才产生 Gather Job。
- 采集完成释放格子，生成真实地面资源堆。
- 资源堆使用已有 `ResourceContainerRole.Output`，因此不需要单独写一套“采集物运输”逻辑。

这样自然资源直接接入既有物流系统，而不是采集结束后直接增加全局数字。

## 五行环境场

新增 `FiveElementField` 与 `FiveElementSource`。

五种场值按距离平方衰减并缓存到格子：木、火、土、金、水。自然资源、灵脉和部分建筑都可以成为五行源。

当前采用简化但可解释的生产公式：

- 同属性环境：小幅支持。
- 生我者：较强支持。
- 克我者：较强压制。
- 最终把环境支持值换算成约 0.65x–1.5x 的工作效率区间，再按建筑的 `environmentSensitivity` 缩放。

关系遵循：

- 相生：木 → 火 → 土 → 金 → 水 → 木。
- 相克：木克土、土克水、水克火、火克金、金克木。

当前影响的是生产/修炼 Job 的工作耗时，而不是简单 UI 百分比。这样五行布局会直接改变吞吐效率。

示例：

- 灵田属木：水性环境支持，金性环境压制。
- 炼制工坊属火：木性环境支持，水性环境压制。
- 蒲团属水：金性环境支持，土性环境压制。

## UI

当前 UI 都只服务经营判断：

- 底部：7 类建筑工具栏和成本。
- 左上：仓库过滤与物流优先级。
- 右上：弟子当前行为、需求和 6 类工作优先级。
- 顶部中央：鼠标所在格的灵气、木火土金水以及道路状态。

自然资源点无需额外菜单：未选择建筑时直接左键点击即可指定采集，被指定节点会变亮。

## 系统原则

- 所有长期生产/采集行为尽量转成 Job。
- 资源必须存在于具体容器或地面资源堆。
- 建筑内容由 ScriptableObject 数据定义。
- 距离、道路、占地和环境都必须最终反馈到实际效率，而不是只做描述性数值。
- 地图场按 Dirty Cache 更新，不每帧重算。
- 角色属性只有影响经营决策时才增加。
- 随机事件仍保持低优先级。

## 下一批实现

下一步不再继续横向加系统，而是加强“看得懂瓶颈、能做优化”：

- 建筑详情面板：输入库存、输出库存、当前 Job、五行效率、等待原因。
- 产能统计：单位时间产出、搬运占比、空转原因。
- 道路批量拖拽建造，避免一格一格点。
- 建筑旋转，让 1x2 / 2xN 布局更有意义。
- 突破准备界面，把灵气、环境、丹药和风险接成一次明确决策。
- 探索地图与高级资源点占领。
- 存档系统。
- 微信小游戏/Web 性能档位。
