# 玩法架构 v0.1

## 目标

第一阶段不做复杂关系、导演、剧情生成。只验证：建设、生产、劳动力分配、灵气布局、修炼成长是否本身好玩。

## 第一层循环

1. 建灵田解决食物与药材。
2. 建工坊把基础资源转成灵石。
3. 建聚灵设施改善局部灵气。
4. 建蒲团，让弟子消耗劳动力时间换修为。
5. 新资源与更高境界解锁下一层生产链。

## 系统原则

- 所有长期行为尽量转成 Job，不直接把 NPC 写死在建筑逻辑里。
- 所有地图场都按 Dirty Cache 更新，避免每帧全地图重算。
- 建筑数据后续迁移到 ScriptableObject 数据层；当前原型先验证循环。
- 角色复杂属性只有在影响玩家决策时才增加。
- 随机事件只负责改变经营条件，不负责替玩家“讲故事”。
