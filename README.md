# 山门（暂定名）

修仙题材模拟经营原型。核心目标是“玩家持续解决经营瓶颈”，而不是自动讲故事。

核心循环：建设布局 → 生产资源 → 发现瓶颈 → 调整人员/空间 → 修炼突破 → 获得高级资源 → 解锁新生产链。

## 当前原型已落地

- Tick 游戏时间
- 格子地图与建筑占地
- 木材 / 石料 / 食物 / 药材 / 灵石资源账本
- 建筑建造与成本
- Job 工作队列、预约、完成
- 弟子自动取 Job 并移动执行
- 灵田生产链
- 工坊生产链
- 蒲团修炼工作
- 灵气源与按格缓存的灵气场
- 修为 / 境界 / 突破条件基础
- 编辑器一键生成 Prototype 场景
- 快捷建造与开发日志状态输出

## 启动

1. 使用 Unity 6.3 LTS 打开项目目录。
2. Unity 首次导入后，在菜单选择 `Tools > ShanMen > Create Prototype Scene`。
3. 打开生成的 `Assets/Game/Scenes/Prototype.unity`，进入 Play。
4. `1/2/3/4` 选择建筑，鼠标左键放置，右键取消；`B` 让第一个满足条件的弟子尝试突破。

> 当前没有手工写 `Packages/manifest.json`；首次由 Unity 建立/解析包配置。
