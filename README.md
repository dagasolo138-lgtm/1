# 山门（暂定名）

修仙题材模拟经营原型。核心目标是“玩家持续解决经营瓶颈”，而不是让系统自动讲故事。

核心循环：建设布局 → 搬运材料 → 生产加工 → 满足弟子生活需求 → 发现瓶颈 → 调整人员/空间/物流 → 修炼突破 → 解锁新生产链。

## 当前原型已落地

- Tick 游戏时间
- 格子地图与建筑占地
- 真实资源容器：仓库 / 建筑输入 / 建筑输出 / 工地材料 / 地面返料
- 真实搬运 Job：弟子走到来源取货，再走到目标交货
- 真实施工流程：放置工地 → 搬材料 → Build Job → 完工
- 工地取消：已送达材料变成地面返料堆，再由弟子搬回仓库
- 数据驱动建筑：`BuildingDefinition` ScriptableObject
- Job 工作队列、预约、完成
- 每个弟子的搬运 / 建造 / 种植 / 制造 / 修炼优先级
- 工作优先级 UI，并显示弟子当前工作、饱食与体力
- 建筑工具栏：直接显示建筑与建造成本
- 仓库过滤：可逐项允许/禁止木、石、食物、药材、灵石
- 仓库物流优先级：高优先仓优先接货，也会从低优先仓调货
- 弟子饥饿：自动寻找食物并真实消耗库存
- 弟子体力：低体力降低效率，并自动寻找空床休息
- 灵田：生产食物和灵草，产物需要搬回仓库
- 工坊：先搬入灵草，再加工成灵石，再搬回仓库
- 蒲团修炼工作
- 简易床与床位占用
- 仓库容量与可扩建仓库
- 灵气源与按格缓存的灵气场
- 修为 / 境界 / 突破条件基础
- 编辑器一键生成 Prototype 场景与默认建筑数据

## 启动

1. 使用 Unity 6.3 LTS 打开项目目录。
2. Unity 首次导入后，在菜单选择 `Tools > ShanMen > Create Prototype Scene`。
3. 打开生成的 `Assets/Game/Scenes/Prototype.unity`，进入 Play。
4. 可直接使用底部建筑工具栏；快捷键为：`1 灵田`、`2 炼制工坊`、`3 蒲团`、`4 聚灵台`、`5 仓库`、`6 简易床`。
5. 选择建筑后鼠标左键放置、右键取消选择；未选择建筑时，右键点击工地可取消施工并返料。
6. 左上仓库面板可调物流优先级和资源过滤；右上工作面板可调整弟子工作优先级并查看需求状态。
7. `B`：让第一个满足条件的弟子尝试突破。

## 现在能验证什么

资源、距离、劳动力和生活需求已经开始互相形成瓶颈。

例如建工坊时，弟子先从仓库把木材和石料搬到工地；工坊建好后，灵草必须先被搬进输入槽才能制造，成品灵石再被搬回仓库。新建高优先仓后，物流会自动把资源重新调配过去。弟子饿了会消耗食物，累了需要床位，否则移动与工作效率都会降低。

这意味着玩家已经开始需要同时考虑：仓库放哪里、谁负责搬运、哪些仓库存什么、床位够不够、食物产量够不够，以及修炼是否挤占生产劳动力。

> 项目仍处于玩法原型阶段，美术暂不投入资源，先验证经营循环和决策密度。
