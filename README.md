# 山门（暂定名）

修仙题材模拟经营原型。核心目标是“玩家持续解决经营瓶颈”，而不是让系统自动讲故事。

核心循环：勘察地图 → 采集自然资源 → 建设与修路 → 搬运生产 → 满足弟子需求 → 根据灵气/五行调整布局 → 修炼突破 → 解锁更高级生产链。

## 当前原型已落地

- Tick 游戏时间
- 格子地图、真实多格建筑占地与阻挡
- A* 格子寻路，弟子不再直接穿过建筑
- 石板路：降低寻路成本并提高实际移动速度，A* 会主动偏好道路
- 地图自然资源：古灵木、巨石、金纹矿、灵草丛、灵晶
- 玩家左键点击自然资源点后才会生成 Gather Job，不会自动扫光地图
- 采集产物落地成真实资源堆，再由搬运系统运入仓库
- 独立“采集”工作优先级
- 真实资源容器：仓库 / 建筑输入 / 建筑输出 / 工地材料 / 地面资源
- 真实搬运 Job：弟子走到来源取货，再走到目标交货
- 真实施工流程：放置工地 → 搬材料 → Build Job → 完工
- 工地取消：已送达材料变成地面返料堆，再由弟子搬回仓库
- 数据驱动建筑：`BuildingDefinition` ScriptableObject
- 建筑工具栏：直接显示建筑与建造成本
- 仓库过滤与物流优先级
- 弟子饥饿、体力、吃饭与床位休息
- 灵田 / 炼制工坊 / 蒲团 / 聚灵台 / 仓库 / 简易床 / 石板路
- 灵气源与按格缓存的灵气场
- 五行环境场：木、火、土、金、水按距离形成场值
- 五行生克实际影响建筑工作耗时：相生环境更快、相克环境更慢
- 鼠标悬停地图时显示当前格灵气与五行数值
- 修为 / 境界 / 突破条件基础
- 编辑器一键生成 Prototype 场景与默认建筑数据

## 启动

1. 使用 Unity 6.3 LTS 打开项目目录。
2. 在菜单选择 `Tools > ShanMen > Create Prototype Scene`，重新生成最新原型场景与建筑 Definition。
3. 打开 `Assets/Game/Scenes/Prototype.unity`，进入 Play。
4. 底部建筑工具栏对应快捷键：`1 灵田`、`2 炼制工坊`、`3 蒲团`、`4 聚灵台`、`5 仓库`、`6 简易床`、`7 石板路`。
5. 选择建筑后左键放置、右键取消；未选择建筑时，右键工地可取消施工并返料。
6. 未选择建筑时，左键点击古灵木、矿石、灵草、灵晶等自然资源，可指定采集；被指定的资源点会变亮。
7. 左上仓库面板调物流优先级与资源过滤；右上弟子面板调搬运 / 建造 / 采集 / 种植 / 制造 / 修炼优先级。
8. 屏幕上方环境条显示鼠标所在格的灵气、木火土金水数值以及是否为道路。
9. `B`：让第一个满足条件的弟子尝试突破。

## 当前可以验证的玩法

初始库存被刻意压低，地图上的木材、石料、灵草和灵晶开始成为实际发展来源。玩家需要决定先采什么、谁去采、资源运回哪个仓库，以及是否值得先花石料铺路来降低未来长期物流成本。

空间也不再只是装饰：2x2 的灵田、工坊、仓库和聚灵台会真实挡路，弟子会绕行；连续道路会被寻路系统优先选择，因此“仓库—生产区—资源点”的道路网络能够直接改变吞吐效率。

五行则提供第二层布局取舍。例如灵田属木，水性环境对它有利、金性环境会压制；工坊属火，靠近木性环境更有效率，而靠近强水性灵脉会变慢。玩家因此需要在“灵气高”“物流近”“五行合适”之间权衡。

> 项目仍处于玩法原型阶段。当前优先验证经营循环、空间规划和决策密度，美术暂不投入资源。
