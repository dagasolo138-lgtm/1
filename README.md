# 山门（暂定名）

修仙题材模拟经营原型。核心目标是“玩家持续解决经营瓶颈”，而不是让系统自动讲故事。

核心循环：建设布局 → 搬运材料 → 生产加工 → 发现瓶颈 → 调整人员/空间 → 修炼突破 → 获得高级资源 → 解锁新生产链。

## 当前原型已落地

- Tick 游戏时间
- 格子地图与建筑占地
- 真实资源容器：仓库 / 建筑输入 / 建筑输出 / 工地材料
- 真实搬运 Job：弟子走到来源取货，再走到目标交货
- 真实施工流程：放置工地 → 搬材料 → Build Job → 完工
- 数据驱动建筑：`BuildingDefinition` ScriptableObject
- Job 工作队列、预约、完成
- 每个弟子的搬运 / 建造 / 种植 / 制造 / 修炼优先级
- 运行时工作优先级 UI，可点击 0-5 调整
- 灵田：生产食物和灵草，产物需要搬回仓库
- 工坊：先搬入灵草，再加工成灵石，再搬回仓库
- 蒲团修炼工作
- 仓库容量与可扩建仓库
- 灵气源与按格缓存的灵气场
- 修为 / 境界 / 突破条件基础
- 编辑器一键生成 Prototype 场景与默认建筑数据

## 启动

1. 使用 Unity 6.3 LTS 打开项目目录。
2. Unity 首次导入后，在菜单选择 `Tools > ShanMen > Create Prototype Scene`。
3. 打开生成的 `Assets/Game/Scenes/Prototype.unity`，进入 Play。
4. 建造快捷键：`1 灵田`、`2 炼制工坊`、`3 蒲团`、`4 聚灵台`、`5 仓库`。
5. 鼠标左键放置，右键取消；右上工作面板点击数字切换 0-5 优先级。
6. `B`：让第一个满足条件的弟子尝试突破。

## 现在能验证什么

最关键的变化是：资源不再只是一个总数字。

例如建工坊时，弟子会先从仓库把木材和石料搬到工地；工坊建好后，灵草必须先被搬进输入槽才能制造，成品灵石也必须再被搬回仓库。距离、搬运优先级、仓库位置已经开始影响实际效率。

> 项目仍处于玩法原型阶段，美术和正式 UI 暂不投入资源。
